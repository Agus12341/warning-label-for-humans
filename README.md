# warning-label-for-humans - one safety warning label

An entry for make.fun's [Warning Label for Humans](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty.

`main.py` writes one line, the safety warning label that should come printed on every human being, to `/output/entry.txt`:

> DANGER: This human runs on 4 hours of sleep and spite. Approach with food, leave slowly.
